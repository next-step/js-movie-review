## 학습 목표 

- 비동기 🔥

    - API 연동을 위한 테스트 환경 경험
    - 실제 동작하는 API를 통한 비동기 통신 UX

    - UX 경험을 위한 더 보기(페이징) 구현

-  UX
    
    - UX 경험을 위한 무한 스크롤 구현
    
    - 반응형 웹 페이지 구현


### 1. 기능적 요구 사항 

1. 영화 목록 조회(인기순)

    - 영화 목록 API의 1페이지를 불러오며, 더보기 버튼을 누르면 그 다음의 영화 목록을 불러올 수 있음 

2. 영화 검색 API를 이용해 내가 보고 싶은 영화를 검색 할 수 있다  

3. 영화 상세 정보 조회

- API에서 제공하는 항목을 활용하여 상세 정보를 보여주는 모달 창을 구현한다.

- 키보드의 ESC 키를 누르면 모달 창을 닫을 수 있는 등 사용성을 고려한다.
